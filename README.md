# 기능 요구 사항

- 움직임은 전진과 멈춤 o
- 몇번 이동할지 횟수가 사용자가 입력 할 수 있어야 함. (Readline) 함수로 입력 o
- , 쉼표를 구분자로 사용하 되, 글자는 5자 이하로 o
- 전진하는 조건은 0~9 사이에서 무작위 값을 구하고 무작위 값이 4이상인 경우에만 전진. o
- 횟수가 전부 소진되면 누가 우승했는지 우승자는 한 명 이상 일 수 있음 → 동점도 같이 우승으로 o
- 우승자가 여러 명일 경우에는 출력 값을 , 쉼표로 표시 o
- 사용자가 잘못된 값을 입력한 경우 IllegalArgumentException 발생시키고 애플리케이션이 종료 o

## 프로그램 요구 사항

- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
    - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
    - 힌트: indent(인덴트, 들여쓰기) depth를 줄이는 좋은 방법은 함수(또는 메서드)를 분리하면 된다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.

-> 여기서 파악해야할게 depth가 메서드안에서 전체적으로 3이 넘으면 안되는건지 아니면 while 문 사용하고 if 사용시 2라고 들여쓰기가 while 안에 for 쓰고 if 쓰면 depth 가 전체적으로는 3이상이 되는데 이 경우를 사용하면 안되는지 파악이 어려워서
